# 条件判断系统使用说明

## 概述

条件判断系统是一个通用、简单、实用的跳过步骤机制，支持多种条件格式和操作符，可以灵活控制测试步骤的执行。

## 使用场景

- 根据前置步骤的结果决定是否跳过当前步骤
- 根据变量的值进行条件判断
- 组合多个条件进行复杂判断

## 支持的格式

### 1. 字符串格式（向后兼容，简单场景）

#### 1.1 简单变量名
```yaml
skip_when: "var_name"
```
- **说明**：如果变量为空/None/不存在，则跳过步骤
- **示例**：
```yaml
skip_when: positionCodeList  # 如果 positionCodeList 为空则跳过
```

#### 1.2 表达式字符串
```yaml
skip_when: '"value" not in var_name'
```
- **说明**：支持简单的表达式判断
- **支持的表达式**：
  - `"var_name is None"`
  - `"var_name == []"`
  - `'"value" not in var_name'`
  - `'"value" in var_name'`
  - `"var_name == value"`
  - `"var_name != value"`
- **示例**：
```yaml
skip_when: '"471053556092895232" not in positionCodeList'
```

### 2. 字典格式（推荐，功能强大）

#### 2.1 单条件
```yaml
skip_when:
  var: var_name           # 变量名（必填）
  operator: operator_type # 操作符（必填）
  value: expected_value   # 期望值（可选，某些操作符需要）
```

**示例**：
```yaml
# 检查变量是否不包含某个值
skip_when:
  var: positionCodeList
  operator: not_contains
  value: "471053556092895232"

# 检查变量是否为空
skip_when:
  var: dataList
  operator: empty

# 检查变量是否等于某个值
skip_when:
  var: status
  operator: equals
  value: "active"
```

#### 2.2 组合条件（AND/OR）
```yaml
skip_when:
  logic: or  # 或 and（必填）
  conditions:  # 条件列表（必填）
    - var: var1
      operator: empty
    - var: var2
      operator: equals
      value: "test"
```

**示例**：
```yaml
# OR 逻辑：任一条件满足则跳过
skip_when:
  logic: or
  conditions:
    - var: positionCodeList
      operator: is_none
    - var: positionCodeList
      operator: empty
    - var: positionCodeList
      operator: not_contains
      value: "471053556092895232"

# AND 逻辑：所有条件都满足才跳过
skip_when:
  logic: and
  conditions:
    - var: userCount
      operator: gte
      value: 100
    - var: status
      operator: equals
      value: "active"
```

### 3. 列表格式（多个条件，默认 OR）
```yaml
skip_when:
  - var: var1
    operator: empty
  - var: var2
    operator: equals
    value: "test"
```
- **说明**：如果任一条件满足，则跳过步骤

## 支持的操作符

### 空值判断
- `empty`: 变量为空（None/[]/''）
- `not_empty`: 变量不为空
- `is_none`: 变量为 None
- `is_not_none`: 变量不为 None

### 相等判断
- `equals`: 等于（需要 value）
- `not_equals`: 不等于（需要 value）

### 包含判断
- `contains`: 包含（需要 value，适用于 list/str/dict）
- `not_contains`: 不包含（需要 value，适用于 list/str/dict）
- `in`: 值在变量中（需要 value，value 在 var 中）
- `not_in`: 值不在变量中（需要 value，value 不在 var 中）

### 数值比较
- `gt`: 大于（需要 value，数值比较）
- `gte`: 大于等于（需要 value，数值比较）
- `lt`: 小于（需要 value，数值比较）
- `lte`: 小于等于（需要 value，数值比较）

## 完整示例

### 示例1：根据查询结果决定是否清空数据
```yaml
- step_name: 前置步骤-查询现有仓位代码
  host: $get_host(ERP_TEST,pms_host)
  path: /technology/inventory/getStockBingPositionNumByStockCode
  method: POST
  data:
    stockCode: "1984098091523760130"
  extract:
    - extract: $set_variable(positionCodeList,$get_response_data($.data[].positionCode))

- step_name: 前置步骤-清空已存在的仓位代码
  host: $get_host(ERP_TEST,pms_host)
  path: /technology/inventory/clearStockBingPositionCodes
  method: POST
  data:
    stockCode: "1984098091523760130"
    toBeDeletePositionCodes:
    - "471053556092895232"
  # 如果 positionCodeList 不包含目标仓位码，则跳过清空步骤
  skip_when:
    var: positionCodeList
    operator: not_contains
    value: "471053556092895232"
```

### 示例2：组合条件判断
```yaml
- step_name: 条件步骤
  # 如果 userCount >= 100 且 status == "active"，则跳过
  skip_when:
    logic: and
    conditions:
      - var: userCount
        operator: gte
        value: 100
      - var: status
        operator: equals
        value: "active"
```

### 示例3：多种格式混用
```yaml
# 方式1：字符串表达式（向后兼容）
skip_when: '"471053556092895232" not in positionCodeList'

# 方式2：字典格式（推荐）
skip_when:
  var: positionCodeList
  operator: not_contains
  value: "471053556092895232"

# 方式3：组合条件
skip_when:
  logic: or
  conditions:
    - var: positionCodeList
      operator: empty
    - var: positionCodeList
      operator: not_contains
      value: "471053556092895232"
```

## 最佳实践

1. **推荐使用字典格式**：更清晰、易读、易维护
2. **复杂条件使用组合条件**：支持 AND/OR 逻辑，更灵活
3. **简单场景可以使用字符串格式**：保持向后兼容
4. **合理使用变量提取**：在前置步骤中提取变量，用于条件判断

## 注意事项

1. 变量名必须在前置步骤中已经提取或定义
2. 某些操作符需要提供 `value` 参数
3. 数值比较会自动转换为浮点数进行比较
4. 包含判断适用于 list、str、dict 类型
5. 如果条件评估失败（异常），默认不跳过步骤
