## 🎯 一句话总结

**是的，数据库和 Redis 必须本地安装部署！** 项目依赖 PostgreSQL 存储数据和 Redis 缓存。

---

## ⚡ 最快部署方式（5分钟）

### 前提条件
- 已安装 Docker 和 Docker Compose

### 步骤

```bash
# 1. 进入部署目录
cd AI_TEST/scripts/deploy

# 2. 启动数据库和 Redis
docker compose -f docker-compose.simple.yml up -d

# 3. 验证服务
docker compose ps

# 4. 访问前端（如果 Nginx 已启动）
# http://localhost/?code=190787210592256000
```

## ❓ 常见问题

### Q: 数据库和 Redis 必须本地安装吗？

**A: 是的，必须安装！**

原因：
1. 后端代码中有大量 SQL 文件，需要 PostgreSQL 数据库
2. 代码使用了 Redis 缓存（forest-cache 模块）
3. 应用启动时会连接数据库和 Redis

### Q: 可以用云数据库吗？

**A: 可以，但需要：**
- 修改配置文件中的数据库连接地址
- 确保虚拟机能访问云服务
- 配置安全组和防火墙

### Q: 最小化部署需要什么？

**A: 最小化部署只需要：**
1. PostgreSQL（数据库）
2. Redis（缓存）
3. 后端服务（Java 应用）
4. 前端静态文件（Nginx 或简单 HTTP 服务器）

### Q: 后端如何构建？

**A: 需要按顺序构建各个模块：**
```bash
cd servercode/170server
# 1. forest-master
# 2. pms-master
# 3. pms-base-master
# 4. pms-core-master
# 5. pms-application-master
# 6. pms-customization-master
```

每个模块执行：`mvn clean install -DskipTests`
