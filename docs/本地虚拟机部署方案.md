# PMS 系统本地虚拟机部署方案

## 📋 项目分析

### 技术栈识别

**后端 (170server)**:
- **语言**: Java 21
- **框架**: Spring Boot 3.3.2
- **微服务**: Spring Cloud 2023.0.1.2
- **配置中心**: Nacos
- **构建工具**: Maven
- **数据库**: PostgreSQL
- **缓存**: Redis
- **消息队列**: RocketMQ (可选)

**前端 (front)**:
- **类型**: 打包后的静态文件（Vite 构建）
- **部署**: 可直接用 Nginx 或简单 HTTP 服务器

### 项目模块结构

```
170server/
├── forest-master/              # 基础框架
├── pms-master/                 # 主框架
├── pms-base-master/            # 基础服务（系统、企业、文件、邮件）
├── pms-core-master/            # 核心业务（数据管理、流程、权限）
├── pms-application-master/    # 应用层（用户导向、运营、消息）
└── pms-customization-master/  # 定制化模块（技术、PAS）
```

## 📦 部署方案一：Docker Compose（推荐）

### 优势
- ✅ 一键部署，环境隔离
- ✅ 易于管理和维护
- ✅ 支持快速扩展
- ✅ 数据库和 Redis 自动部署

### 步骤

#### 1. 安装 Docker 和 Docker Compose

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo apt-get install docker-compose-plugin

# 验证安装
docker --version
docker compose version
```

#### 2. 创建部署目录结构

```bash
mkdir -p ~/pms-deploy/{postgres,redis,nginx,backend,frontend}
cd ~/pms-deploy
```

#### 3. 创建 docker-compose.yml

```yaml
version: '3.8'

services:
  # PostgreSQL 数据库
  postgres:
    image: postgres:15-alpine
    container_name: pms-postgres
    environment:
      POSTGRES_DB: micgenerp
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      PGDATA: /var/lib/postgresql/data/pgdata
    ports:
      - "5432:5432"
    volumes:
      - ./postgres/data:/var/lib/postgresql/data
      - ./postgres/init:/docker-entrypoint-initdb.d
    networks:
      - pms-network
    restart: unless-stopped
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Redis 缓存
  redis:
    image: redis:7-alpine
    container_name: pms-redis
    command: redis-server --requirepass zhongzao --appendonly yes
    ports:
      - "6379:6379"
    volumes:
      - ./redis/data:/data
    networks:
      - pms-network
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "redis-cli", "--raw", "incr", "ping"]
      interval: 10s
      timeout: 3s
      retries: 5

  # Nacos 配置中心（可选，如果项目需要）
  nacos:
    image: nacos/nacos-server:v2.3.0
    container_name: pms-nacos
    environment:
      MODE: standalone
      SPRING_DATASOURCE_PLATFORM: postgresql
      MYSQL_SERVICE_HOST: postgres
      MYSQL_SERVICE_DB_NAME: nacos
      MYSQL_SERVICE_PORT: 5432
      MYSQL_SERVICE_USER: postgres
      MYSQL_SERVICE_PASSWORD: postgres
    ports:
      - "8848:8848"
      - "9848:9848"
    depends_on:
      - postgres
    networks:
      - pms-network
    restart: unless-stopped

  # 后端服务
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: pms-backend
    environment:
      SPRING_PROFILES_ACTIVE: dev
      SPRING_DATASOURCE_URL: jdbc:postgresql://postgres:5432/micgenerp
      SPRING_DATASOURCE_USERNAME: postgres
      SPRING_DATASOURCE_PASSWORD: postgres
      SPRING_REDIS_HOST: redis
      SPRING_REDIS_PORT: 6379
      SPRING_REDIS_PASSWORD: zhongzao
    ports:
      - "3356:3356"  # FPI 端口
      - "3456:3456"  # OPI 端口
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    networks:
      - pms-network
    restart: unless-stopped
    volumes:
      - ./backend/logs:/app/logs

  # Nginx 前端
  nginx:
    image: nginx:alpine
    container_name: pms-nginx
    ports:
      - "80:80"
      - "3356:3356"  # 如果需要通过 Nginx 代理后端
    volumes:
      - ./frontend:/usr/share/nginx/html
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf
    depends_on:
      - backend
    networks:
      - pms-network
    restart: unless-stopped

networks:
  pms-network:
    driver: bridge
```

#### 4. 创建后端 Dockerfile

```dockerfile
# backend/Dockerfile
FROM maven:3.9-eclipse-temurin-21 AS build

WORKDIR /app

# 复制所有 pom.xml 文件
COPY servercode/170server/*/pom.xml ./
COPY servercode/170server/*/*/pom.xml ./

# 下载依赖（利用 Docker 缓存）
RUN mvn dependency:go-offline -B || true

# 复制源代码
COPY servercode/170server/ ./

# 构建项目
RUN mvn clean package -DskipTests

# 运行阶段
FROM eclipse-temurin:21-jre-alpine

WORKDIR /app

# 复制构建产物
COPY --from=build /app/*/target/*.jar app.jar

# 暴露端口
EXPOSE 3356 3456

# 启动应用
ENTRYPOINT ["java", "-jar", "app.jar"]
```

#### 5. 创建 Nginx 配置

```nginx
# nginx/nginx.conf
events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # 前端静态文件
    server {
        listen 80;
        server_name localhost;
        root /usr/share/nginx/html;
        index index.html;

        location / {
            try_files $uri $uri/ /index.html;
        }

        # 代理后端 API
        location /fpi/ {
            proxy_pass http://backend:3356/fpi/;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }

        location /opi/ {
            proxy_pass http://backend:3456/opi/;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

#### 6. 部署步骤

```bash
# 1. 复制前端文件
cp -r AI_TEST/servercode/front/* ~/pms-deploy/frontend/

# 2. 复制后端代码
cp -r AI_TEST/servercode/170server ~/pms-deploy/backend/

# 3. 启动所有服务
cd ~/pms-deploy
docker compose up -d

# 4. 查看日志
docker compose logs -f

# 5. 初始化数据库（如果需要）
# 将 SQL 文件放到 postgres/init/ 目录下
```

## 📦 部署方案二：传统安装（适合生产环境）

### 步骤

#### 1. 安装 Java 21

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-21-jdk

# 验证
java -version
```

#### 2. 安装 Maven

```bash
sudo apt install maven
mvn -version
```

#### 3. 安装 PostgreSQL

```bash
# Ubuntu/Debian
sudo apt install postgresql postgresql-contrib

# 启动服务
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 创建数据库
sudo -u postgres psql
CREATE DATABASE micgenerp;
CREATE USER postgres WITH PASSWORD 'postgres';
GRANT ALL PRIVILEGES ON DATABASE micgenerp TO postgres;
\q
```

#### 4. 安装 Redis

```bash
# Ubuntu/Debian
sudo apt install redis-server

# 配置密码
sudo nano /etc/redis/redis.conf
# 找到 # requirepass foobared，改为：
requirepass zhongzao

# 启动服务
sudo systemctl start redis-server
sudo systemctl enable redis-server

# 验证
redis-cli -a zhongzao ping
```

#### 5. 构建后端

```bash
cd AI_TEST/servercode/170server

# 按顺序构建各个模块
cd forest-master/forest-master && mvn clean install -DskipTests
cd ../../pms-master/pms-master && mvn clean install -DskipTests
cd ../../pms-base-master/pms-base-master && mvn clean install -DskipTests
cd ../../pms-core-master/pms-core-master && mvn clean install -DskipTests
cd ../../pms-application-master/pms-application-master && mvn clean package -DskipTests
cd ../../pms-customization-master/pms-customization-master && mvn clean package -DskipTests
```

#### 6. 配置应用

创建 `application-dev.yml`:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/micgenerp
    username: postgres
    password: postgres
    driver-class-name: org.postgresql.Driver
  
  redis:
    host: localhost
    port: 6379
    password: zhongzao
    database: 0

server:
  port: 3356
```

#### 7. 启动后端

```bash
# 找到主启动类（通常在 pms-application-master 或 pms-user-oriented-bff）
java -jar target/pms-user-oriented-bff-*.jar --spring.profiles.active=dev
```

#### 8. 部署前端

```bash
# 安装 Nginx
sudo apt install nginx

# 复制前端文件
sudo cp -r AI_TEST/servercode/front/* /var/www/html/

# 配置 Nginx
sudo nano /etc/nginx/sites-available/pms

# 内容同上面的 nginx.conf

# 启用配置
sudo ln -s /etc/nginx/sites-available/pms /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 🔧 数据库和 Redis 部署说明

### 是否需要本地安装？

**答案：是的，必须安装！**

原因：
1. **PostgreSQL**: 后端代码中有大量 SQL 文件，需要数据库存储业务数据
2. **Redis**: 代码中使用了 `forest-cache` 模块，Redis 用于缓存和会话管理

### 部署选项

#### 选项 A：Docker Compose（推荐）
- ✅ 自动安装和配置
- ✅ 数据持久化到本地目录
- ✅ 易于备份和恢复
- ✅ 环境隔离

#### 选项 B：本地安装
- ✅ 性能更好（无容器开销）
- ✅ 适合生产环境
- ❌ 需要手动配置和维护

#### 选项 C：使用云服务（如果虚拟机有网络）
- 可以使用云数据库和 Redis（如阿里云、腾讯云）
- 需要修改配置文件中的连接地址

## 🔍 常见问题

### 1. 数据库连接失败
- 检查 PostgreSQL 是否启动
- 检查防火墙设置
- 验证用户名密码

### 2. Redis 连接失败
- 检查 Redis 是否启动
- 验证密码是否正确
- 检查端口是否被占用

### 3. 后端启动失败
- 检查 Java 版本（需要 Java 21）
- 查看日志文件
- 检查端口是否被占用

### 4. 前端无法访问后端
- 检查 Nginx 配置
- 检查后端服务是否启动
- 检查 CORS 配置

## 📦 数据迁移（从测试环境到本地）

部署完成后，需要将测试环境的数据迁移到本地：

### 快速迁移

```bash
# Python 版本（推荐）
pip install psycopg2-binary redis
python scripts/deploy/migrate_data.py

# Shell 版本
bash scripts/deploy/migrate_data.sh

# PowerShell 版本（Windows）
powershell -ExecutionPolicy Bypass -File scripts/deploy/migrate_data.ps1
```

### 手动迁移

**PostgreSQL**:
```bash
# 备份
pg_dump -h 192.168.2.172 -p 5432 -U postgres -d micgenerp -F c -f backup.dump

# 恢复
docker exec -i pms-postgres pg_restore -U postgres -d micgenerp -c < backup.dump
```

**Redis**:
```bash
# 备份
redis-cli -h 192.168.2.180 -p 6379 -a zhongzao --rdb dump.rdb

# 恢复
docker stop pms-redis
docker cp dump.rdb pms-redis:/data/dump.rdb
docker start pms-redis
```

详细说明请参考: [数据迁移指南](数据迁移指南.md) | [数据迁移快速参考](数据迁移快速参考.md)
