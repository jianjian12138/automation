# Playwright 最佳实践改进实施总结

## ✅ 已完成的改进（优先级1）

### 1. 支持测试标签（@smoke / @full）✅

**实现内容**:
- ✅ 转换工具自动识别用例并添加标签
- ✅ 在 YAML 用例中添加 `tags` 字段
- ✅ 在 `main.py` 中添加 `--tags` 参数支持
- ✅ 在 `case_context.py` 中添加标签过滤逻辑

**标签规则**:
- `smoke`: 登录、关键流程（支付、下单等）
- `critical`: 关键业务功能
- `full`: 步骤较多（>20步）或完整流程

**使用示例**:
```bash
# 只运行冒烟测试
python main.py cases/web/6000/ --type web --tags smoke

# 运行完整回归测试
python main.py cases/web/6000/ --type web --tags full

# 运行多个标签的用例
python main.py cases/web/6000/ --type web --tags smoke critical
```

**YAML 用例示例**:
```yaml
case_name: 销售合同
case_code: SalesContract
priority: 1
tags:
  - smoke
  - critical
  - full
case_variables:
  ...
```

### 2. 优化选择器策略（优先 data-testid）✅

**实现内容**:
- ✅ 转换工具优先识别 `getByTestId()` 调用
- ✅ 生成 `t,testid` 格式的选择器（最稳定）
- ✅ 优化 `getByRole()` 生成 `r,role,name` 格式（Playwright 推荐）

**选择器优先级**:
1. `data-testid` → `t,testid` （最稳定）
2. `id` → `s,#id`
3. `role+name` → `r,role,name` （Playwright 推荐）
4. `text` → `x,//*[contains(text(),"xxx")]` （较不稳定）
5. `css` → `s,.class`
6. `xpath` → `x,//xxx`

**示例**:
```yaml
# 最佳实践：使用 data-testid
button_登录: t,login-button  # t, 表示 testid

# 次优：使用 role
button_登录: r,button,登录  # r, 表示 role

# 避免：仅使用文本
button_登录: x,//button[contains(text(),"登录")]
```

---

### 3. 减少硬编码 sleep，使用智能等待✅

**实现内容**:
- ✅ 导航后自动添加 `$wait_for_network_idle()` 替代固定 sleep
- ✅ 优化 `_optimize_steps()` 方法，减少不必要的 sleep
- ✅ 添加智能等待关键字：`wait_for_network_idle()` 和 `wait_for_url()`

**改进前**:
```yaml
- action: $navigate(&url)
  sleep: 2  # 硬编码等待
```

**改进后**:
```yaml
- action: $navigate(&url)
- action: $wait_for_network_idle()  # 智能等待网络空闲
```

**新增关键字**:
- `$wait_for_network_idle(timeout=30000)` - 等待网络空闲
- `$wait_for_url(url_pattern, timeout=30000)` - 等待 URL 匹配

**Sleep 优化规则**:
- 导航后的 sleep >= 1秒 → 移除，使用智能等待
- 点击后的 sleep >= 0.5秒 → 减少到 0.3秒（用于动画）
- 输入后的 sleep >= 0.5秒 → 减少到 0.2秒

## 🔧 技术实现细节

### 1. 标签自动识别逻辑

```python
def _auto_detect_tags(case_name: str, case_steps: List[Dict[str, Any]]) -> List[str]:
    """根据用例名称和步骤自动检测并添加标签"""
    tags = []
    
    # 检测关键功能（自动添加 smoke 和 critical）
    critical_keywords = ["登录", "login", "支付", "payment", "pay", "下单", "order"]
    if any(keyword in case_name.lower() for keyword in critical_keywords):
        tags.append("smoke")
        tags.append("critical")
    
    # 检测完整流程（步骤较多）
    if len(case_steps) > 20:
        tags.append("full")
    
    return tags
```

### 2. 智能等待实现

```python
def wait_for_network_idle(timeout: int = 30000):
    """等待网络空闲（所有网络请求完成）"""
    page.wait_for_load_state("networkidle", timeout=timeout)
```

### 3. 标签过滤逻辑

```python
# 在 case_context.py 中
if self.tags:
    case_tags = case_content.get("tags", [])
    # 用例标签必须包含所有指定的标签
    if not all(tag in case_tags for tag in self.tags):
        continue  # 跳过不匹配的用例
```
