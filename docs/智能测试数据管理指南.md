# 智能测试数据管理指南

## 📖 概述

AI_TEST 框架提供了强大的**智能测试数据管理能力**，支持：

1. **AI 驱动的 Mock 数据生成** - 根据字段名智能推断数据类型
2. **智能数据库查询** - 自动发现表结构，根据字段名查找数据
3. **Redis 数据获取** - 支持模式匹配和缓存变量提取

---

## 🚀 快速开始

### 1. Mock 数据生成

#### 基础用法

```yaml
case_name: 用户注册测试
steps:
  - step_name: 创建新用户
    host: $get_host(ERP_TEST,pms_host)
    path: /user/register
    method: POST
    data:
      userName: $mock_data(userName)           # 自动生成姓名
      phoneNumber: $mock_data(phoneNumber)     # 自动生成手机号
      email: $mock_data(email)                 # 自动生成邮箱
      age: $mock_data(age, int, min=18, max=60)  # 生成 18-60 的年龄
      companyName: $mock_data(companyName)     # 自动生成公司名
```

#### 高级用法

```yaml
# 指定数据类型和约束条件
invoiceAmount: $mock_data(amount, float, min=0.01, max=10000.00, decimals=2)

# 生成编码
contractCode: $mock_data(code, string, length=18)

# 生成日期时间
createTime: $mock_data(createTime, datetime, days_ago=30)

# 生成状态值
status: $mock_data(status, string, options=['正常', '禁用', '待审核'])
```

### 2. 数据库智能查询

#### 自动查找表

框架会自动：
1. 扫描数据库所有表结构
2. 根据字段名查找对应的表
3. 返回查询结果

```yaml
case_name: 合同发票测试
steps:
  - step_name: 使用真实合同编码
    host: $get_host(ERP_TEST,pms_host)
    path: /purchase/contract/invoiceRecord/add
    method: POST
    data:
      # 从数据库自动查找 contract_code 字段并获取值
      contractCode: $get_db_field(contract_code)
      invoiceAmount: 1000.00
      recordBatch: 1
```

#### 带条件查询

```yaml
data:
  # 查找状态为"正常"的合同编码
  contractCode: $get_db_field(contract_code, status='正常')
  
  # 查找指定类型的用户
  userName: $get_db_field(user_name, status='正常', type='企业用户')
```

### 3. Redis 数据获取

#### 获取普通键值

```yaml
data:
  # 获取 Redis 中的用户信息
  userInfo: $get_redis(user:1001)
  
  # 使用模式匹配
  sessionData: $get_redis(session:*)  # 返回第一个匹配的键
```

#### 获取 Hash 字段

```yaml
data:
  # 获取 Hash 的特定字段
  userName: $get_redis(user:1001, name)
  userEmail: $get_redis(user:1001, email)
```

#### 获取缓存变量

```yaml
# 从 environment.yaml 配置中获取缓存变量
data:
  userHash: $get_cache_var(operation_user_hash_key)
  moduleHash: $get_cache_var(module_hash_key)
```

## 📝 支持的变量函数完整列表

### Mock 数据生成

| 函数 | 说明 | 示例 |
|------|------|------|
| `$mock_data(field_name)` | 自动推断类型生成数据 | `$mock_data(userName)` |
| `$mock_data(field_name, type)` | 指定类型生成 | `$mock_data(age, int)` |
| `$mock_data(field_name, type, constraints...)` | 带约束条件生成 | `$mock_data(amount, float, min=0, max=1000)` |

**支持的数据类型**：
- `auto` - 自动推断（默认）
- `string` - 字符串
- `int` - 整数
- `float` - 浮点数
- `bool` - 布尔值
- `date` - 日期
- `datetime` - 日期时间

**支持的约束条件**：
- `min` - 最小值
- `max` - 最大值
- `length` - 长度
- `decimals` - 小数位数
- `options` - 可选值列表
- `days_ago` - 多少天前（用于日期）

### 数据库查询

| 函数 | 说明 | 示例 |
|------|------|------|
| `$get_db_field(field_name)` | 智能查询字段值 | `$get_db_field(contract_code)` |
| `$get_db_field(field_name, conditions)` | 带条件查询 | `$get_db_field(user_name, status='正常')` |

### Redis 数据

| 函数 | 说明 | 示例 |
|------|------|------|
| `$get_redis(key)` | 获取键值 | `$get_redis(user:1001)` |
| `$get_redis(pattern)` | 模式匹配 | `$get_redis(session:*)` |
| `$get_redis(key, field)` | 获取 Hash 字段 | `$get_redis(user:1001, name)` |
| `$get_cache_var(var_name)` | 获取缓存变量 | `$get_cache_var(operation_user_hash_key)` |

## ⚡ 性能优化

### 1. 表结构缓存

数据库查询工具会自动缓存表结构，避免重复扫描：

```python
# 第一次查询时会扫描所有表
data = $get_db_field(contract_code)  # 扫描表结构并缓存

# 后续查询直接使用缓存
data = $get_db_field(user_name)  # 使用缓存，快速查找
```

### 2. 连接复用

数据库和 Redis 连接会自动复用，提高性能。

## 🐛 故障排查

### 问题 1：数据库连接失败

**原因**：配置错误或网络问题

**解决**：
1. 检查 `config/environment.yaml` 中的数据库配置
2. 确认数据库服务正常运行
3. 检查网络连接

### 问题 2：Mock 数据类型不正确

**原因**：字段名没有被正确识别

**解决**：
1. 使用明确的字段名（如 `userName` 而不是 `user`）
2. 或显式指定类型：`$mock_data(user, string)`

### 问题 3：数据库查询未找到数据

**原因**：字段名不存在或条件不匹配

**解决**：
1. 使用数据库工具检查字段是否存在
2. 检查查询条件是否正确
3. 查看日志了解查询过程
