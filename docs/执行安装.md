## 🎯 执行步骤（3步完成）

### 步骤1: 安装Docker（必需）

#### 方式1: 使用一键安装脚本（推荐）

```powershell
# 以管理员身份运行PowerShell

```

脚本会自动：

2. ✅ 如果未安装，提供安装选项（自动或手动）
3. ✅ 自动下载并安装Docker Desktop（如果选择方式1）
4. ✅ 等待Docker启动完成
5. ✅ 启动Jenkins容器
6. ✅ 获取初始密码

#### 方式2: 手动安装Docker

1. **访问Docker官网**
   - 网址: https://www.docker.com/products/docker-desktop/
   - 下载: Docker Desktop Installer.exe

2. **运行安装程序**
   - 双击安装程序
   - 勾选 "Use WSL 2 instead of Hyper-V"（推荐）
   - 点击 "Ok" 开始安装
   - 等待安装完成

3. **重启计算机**（如需要）

4. **启动Docker Desktop**
   - 从开始菜单启动Docker Desktop
   - 等待Docker引擎启动（约30秒）

5. **验证安装**
   ```powershell
   docker --version
   ```

6. **启动Jenkins**
   ```powershell
   # 切换到项目目录
   cd F:\BaiduNetdiskDownload\AT\AI_TEST
   
   # 启动Jenkins
   docker-compose up -d jenkins
   ```

## ⚠️ 注意事项

1. **管理员权限**
   - Docker安装需要管理员权限
   - 请以管理员身份运行PowerShell

2. **系统要求**
   - Windows 10 64位或更高版本
   - 启用虚拟化（Hyper-V或WSL 2）
   - 至少4GB RAM

3. **端口占用**
   - 确保端口8080未被占用
   - 如果被占用，修改 `docker-compose.yml` 中的端口映射

4. **磁盘空间**
   - Docker Desktop需要至少4GB可用空间
   - Jenkins镜像和容器需要约1GB空间

## 🆘 常见问题

### Q1: Docker安装失败

**解决**:
1. 检查系统要求（Windows 10/macOS 10.15/Linux）
2. 确保启用虚拟化（BIOS设置）
3. 尝试手动安装（方式2）

### Q2: Jenkins启动超时

**解决**:
1. 检查Docker是否正常运行: `docker ps`
2. 查看Jenkins日志: `docker logs ai_test_jenkins`
3. 等待更长时间（首次启动需要下载镜像）

### Q3: 端口8080已被占用

**解决**:
1. 查找占用端口的程序: `netstat -ano | findstr :8080`
2. 停止占用端口的程序
3. 或修改 `docker-compose.yml` 中的端口映射

### Q4: Docker daemon 未运行（500 Internal Server Error）

**错误信息**:
```
request returned 500 Internal Server Error for API route and version
unable to get image 'jenkins/jenkins:lts'
```

**原因**: Docker Desktop 未启动或 Docker daemon 未正常运行

**解决步骤**:
1. **启动 Docker Desktop**
   ```powershell
   # 从开始菜单启动 Docker Desktop
   # 或使用命令行启动
   Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
   ```

2. **等待 Docker Desktop 完全启动**
   - 等待托盘图标显示 Docker 正在运行（约30-60秒）
   - 直到图标变为稳定状态（不再是"启动中"）

3. **验证 Docker 是否正常运行**
   ```powershell
   # 检查 Docker 版本
   docker --version
   
   # 检查 Docker daemon 状态
   docker ps
   
   # 如果仍然报错，重启 Docker Desktop
   # 右键点击托盘图标 -> Restart Docker Desktop
   ```

4. **如果 Docker Desktop 无法启动**
   - 检查系统是否支持虚拟化（WSL 2 或 Hyper-V）
   - 尝试重启计算机
   - 检查 Windows 更新是否完整

5. **重新启动 Jenkins**
   ```powershell
   # 确保 Docker 正常运行后
   cd F:\BaiduNetdiskDownload\AT\AI_TEST
   docker-compose up -d jenkins
   ```
