# 🚀 AI_TEST 快速开始指南

> 5分钟上手AI驱动的全栈自动化测试

---

## 📋 前置要求

- **Python**: 3.8+
- **Node.js**: 16+ (Maestro需要)
- **操作系统**: Windows/macOS/Linux

---

## 第一步：安装依赖（5分钟）

### 1.1 安装Python依赖

```bash
cd AI_TEST
pip install -r requirements.txt
```

### 1.2 安装Playwright浏览器

```bash
playwright install chromium
```

### 1.3 安装Maestro（可选）

**macOS/Linux**:
```bash
curl -Ls "https://get.maestro.mobile.dev" | bash
```

**Windows**:
下载安装包: https://maestro.mobile.dev/

---

## 第二步：运行第一个测试（1分钟）

### 2.1 运行Web测试

```bash
# 进入AI_TEST目录
cd AI_TEST

# 运行Playwright示例
python cases/web/examples/test_demo.py

# 或使用pytest
pytest cases/web/examples/test_demo.py::test_baidu_search -v
```

**预期结果**:
- 浏览器自动打开百度
- 搜索"Playwright自动化测试"
- 自动截图
- 生成Trace文件

**查看Trace**:
```bash
playwright show-trace reports/traces/baidu_search.zip
```

### 2.2 运行API测试

```bash
# 运行API测试示例
python core/test_executor.py
```

**预期结果**:
- 自动发送API请求
- 执行断言验证
- 输出JSON格式结果

### 2.3 运行Mobile测试

```bash
# 连接设备或启动模拟器
# 然后运行Maestro测试
maestro test cases/mobile/examples/login.yaml
```

## 第三步：使用Cursor AI生成测试（2分钟）

### 3.1 打开Cursor编辑器

确保你正在Cursor编辑器中打开AI_TEST项目。

### 3.2 生成API测试

**方法1: 使用Composer**
1. 按 `Cmd+I` (macOS) 或 `Ctrl+I` (Windows)
2. 输入提示词:
```
生成一个用户登录接口的测试用例
POST /api/login
参数：username, password
包含5个测试场景
保存到 cases/api/login.yaml
```
3. 按Enter，Cursor自动生成测试用例！

**方法2: 使用Chat**
1. 按 `Cmd+L` 打开Chat
2. 输入:
```
@docs/api_spec.yaml
为用户管理模块生成完整的测试用例
```
3. Cursor分析规范并生成测试

### 3.3 生成Web测试

在Cursor Composer中输入:
```
生成一个登录页面的Playwright测试
URL: https://example.com/login
测试场景：正常登录、错误用户名、错误密码
保存到 cases/web/test_login.py
```

### 3.4 生成Mobile测试

```
生成一个商品搜索的Maestro测试
包含：启动应用、搜索、查看详情、加入购物车
保存到 cases/mobile/product_search.yaml
```

## 第四步：理解框架结构（3分钟）

### 目录结构

```
AI_TEST/
├── .cursorrules          ⭐ Cursor AI配置（核心）
├── requirements.txt      📦 Python依赖
│
├── core/                 🔧 核心引擎
│   ├── playwright_driver.py    # Playwright封装
│   └── test_executor.py        # 测试执行器
│
├── cases/               📝 测试用例
│   ├── web/            # Web测试（Playwright）
│   ├── api/            # API测试（YAML）
│   └── mobile/         # Mobile测试（Maestro）
│
├── config/              ⚙️ 配置文件
│   ├── environment.yaml # 环境配置
│   └── config.yaml      # 框架配置
│
├── reports/             📊 测试报告
│   ├── screenshots/    # 截图
│   ├── traces/         # Playwright Trace
│   └── videos/         # 录屏
│
└── docs/                📖 文档
```

### 核心文件说明

#### 1. `.cursorrules`
定义了AI生成测试用例的规则，包括：
- API测试生成规范
- Web测试生成规范
- Mobile测试生成规范
- 故障诊断规则

#### 2. `core/playwright_driver.py`
Playwright驱动封装，提供：
- 自动等待
- 智能定位
- Trace调试
- 截图录屏

#### 3. `core/test_executor.py`
YAML测试执行器，支持：
- 加载YAML用例
- 发送API请求
- 执行断言
- 提取变量

## 第五步：配置环境（2分钟）

### 5.1 修改环境配置

编辑 `config/environment.yaml`:

```yaml
# 测试环境
test_env:
  api_base_url: "https://api.test.example.com"  # 改为你的API地址
  web_base_url: "https://test.example.com"      # 改为你的Web地址
  mobile_app_id: "com.example.app.test"         # 改为你的App ID
```

### 5.2 修改框架配置

编辑 `config/config.yaml`:

```yaml
# Playwright配置
playwright:
  headless: false  # 改为true可无头运行
  
# 报告配置
report:
  output_dir: "reports"  # 可自定义报告目录
```

## 第六步：调试测试（3分钟）

### 6.1 查看Playwright Trace

当Web测试失败时：

```bash
# 查看最新的Trace
playwright show-trace reports/traces/最新trace文件.zip
```

Trace Viewer功能:
- ✅ 回放每一步操作
- ✅ 查看DOM快照
- ✅ 查看网络请求
- ✅ 查看控制台日志

### 6.2 使用Cursor AI诊断

当测试失败时：
1. 复制错误日志
2. 在Cursor Chat中输入:
```
@test_demo.py
这个测试失败了，错误日志：
[粘贴错误日志]
请分析原因并提供修复方案
```
3. Cursor自动分析并给出修复建议！

### 6.3 查看截图

```bash
# 查看截图目录
ls reports/screenshots/
```

## 常见问题

### Q1: Playwright浏览器下载慢怎么办？

**A**: 设置镜像源:
```bash
# Windows PowerShell
$env:PLAYWRIGHT_DOWNLOAD_HOST="https://npmmirror.com/mirrors/playwright/"
playwright install chromium

# macOS/Linux
export PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/
playwright install chromium
```

### Q2: Cursor AI没有生成测试用例？

**A**: 检查:
1. `.cursorrules`文件是否存在
2. 提示词是否包含关键字（如"生成"、"create"）
3. 尝试在Composer中明确指定保存路径

### Q3: API测试执行失败？

**A**: 
1. 检查`config/environment.yaml`中的URL是否正确
2. 检查网络连接
3. 查看错误日志分析原因

### Q4: 如何查看测试报告？

**A**:
```bash
# Web测试报告
firefox reports/web_report.html

# Playwright Trace
playwright show-trace reports/traces/trace.zip
```
