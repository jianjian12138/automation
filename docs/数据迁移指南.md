# 测试环境数据迁移到本地指南

## 📋 概述

本指南说明如何将测试环境的 PostgreSQL 数据库和 Redis 数据迁移到本地虚拟机。

---

## 🗄️ PostgreSQL 数据库迁移

### 方法一：使用 pg_dump 和 pg_restore（推荐）

#### 步骤 1: 从测试环境备份数据库

```bash
# 在测试服务器或能访问测试数据库的机器上执行
pg_dump -h 192.168.2.172 -p 5432 -U postgres -d micgenerp \
  -F c -f micgenerp_backup.dump

# 或者使用 SQL 格式（更通用）
pg_dump -h 192.168.2.172 -p 5432 -U postgres -d micgenerp \
  -F p -f micgenerp_backup.sql
```

**参数说明**:
- `-h`: 数据库主机地址
- `-p`: 端口号
- `-U`: 用户名
- `-d`: 数据库名
- `-F c`: 自定义格式（压缩，推荐）
- `-F p`: SQL 文本格式（可读，但文件较大）
- `-f`: 输出文件路径

#### 步骤 2: 传输备份文件到本地

```bash
# 使用 SCP（Linux/macOS）
scp user@192.168.2.172:/path/to/micgenerp_backup.dump ./

# 使用 WinSCP 或 FileZilla（Windows）
# 或直接通过共享文件夹、U盘等方式传输
```

#### 步骤 3: 在本地恢复数据库

```bash
# 如果使用 Docker
docker exec -i pms-postgres pg_restore -U postgres -d micgenerp -c < micgenerp_backup.dump

# 或者先复制到容器内
docker cp micgenerp_backup.dump pms-postgres:/tmp/
docker exec -it pms-postgres pg_restore -U postgres -d micgenerp -c /tmp/micgenerp_backup.dump

# 如果使用 SQL 格式
docker exec -i pms-postgres psql -U postgres -d micgenerp < micgenerp_backup.sql

# 如果是本地安装的 PostgreSQL
pg_restore -h localhost -p 5432 -U postgres -d micgenerp -c micgenerp_backup.dump
# 或
psql -h localhost -p 5432 -U postgres -d micgenerp < micgenerp_backup.sql
```

**参数说明**:
- `-c`: 在恢复前清理（删除现有对象）
- `-C`: 创建数据库（如果不存在）
- `-v`: 详细模式

### 方法二：使用 pg_dumpall（备份所有数据库）

```bash
# 备份所有数据库
pg_dumpall -h 192.168.2.172 -p 5432 -U postgres -f all_databases_backup.sql

# 恢复（会恢复所有数据库）
psql -h localhost -p 5432 -U postgres < all_databases_backup.sql
```

### 方法三：直接复制数据目录（不推荐，但最快）

**注意**: 仅适用于相同 PostgreSQL 版本，且需要停止数据库服务。

```bash
# 在测试服务器上
sudo systemctl stop postgresql
sudo tar -czf postgres_data.tar.gz /var/lib/postgresql/data

# 在本地
sudo systemctl stop postgresql
sudo rm -rf /var/lib/postgresql/data/*
sudo tar -xzf postgres_data.tar.gz -C /var/lib/postgresql/
sudo chown -R postgres:postgres /var/lib/postgresql/data
sudo systemctl start postgresql
```

## 🔴 Redis 数据迁移

### 方法一：使用 RDB 文件（推荐）

#### 步骤 1: 在测试环境生成 RDB 快照

```bash
# 连接到测试 Redis
redis-cli -h 192.168.2.180 -p 6379 -a zhongzao

# 在 Redis CLI 中执行
BGSAVE

# 等待完成后，查找 RDB 文件位置
CONFIG GET dir
CONFIG GET dbfilename

# 通常文件在 /var/lib/redis/dump.rdb 或 /data/dump.rdb
```

#### 步骤 2: 复制 RDB 文件

```bash
# 从测试服务器复制
scp user@192.168.2.180:/var/lib/redis/dump.rdb ./

# 或使用其他方式传输
```

#### 步骤 3: 在本地恢复

```bash
# 如果使用 Docker
# 1. 停止 Redis
docker stop pms-redis

# 2. 复制 RDB 文件到数据目录
docker cp dump.rdb pms-redis:/data/dump.rdb

# 3. 启动 Redis（会自动加载 RDB）
docker start pms-redis

# 或者直接挂载文件
# 修改 docker-compose.yml，添加：
# volumes:
#   - ./redis/dump.rdb:/data/dump.rdb
```

### 方法二：使用 redis-cli --rdb（直接导出）

```bash
# 从测试环境直接导出
redis-cli -h 192.168.2.180 -p 6379 -a zhongzao --rdb dump.rdb

# 在本地导入（需要停止 Redis）
# 1. 停止 Redis
docker stop pms-redis

# 2. 复制文件
docker cp dump.rdb pms-redis:/data/dump.rdb

# 3. 启动 Redis
docker start pms-redis
```

### 方法三：使用 redis-dump-go（导出为 JSON）

```bash
# 安装工具
go install github.com/yannh/redis-dump-go@latest

# 导出数据
redis-dump-go -host 192.168.2.180 -port 6379 -password zhongzao > redis_data.json

# 导入数据（需要 redis-load-go 或类似工具）
# 或使用 Python 脚本导入
```

### 方法四：使用 redis-cli MIGRATE（在线迁移）

```bash
# 在本地 Redis 中执行（从测试环境迁移）
redis-cli -h localhost -p 6379 -a zhongzao
> MIGRATE 192.168.2.180 6379 "" 0 5000 COPY KEYS *
```

## 🚀 自动化迁移脚本

### 完整迁移脚本

创建 `scripts/deploy/migrate_data.sh`:

```bash
#!/bin/bash

# 数据库和 Redis 数据迁移脚本

set -e

# 配置
TEST_DB_HOST="192.168.2.172"
TEST_DB_PORT="5432"
TEST_DB_USER="postgres"
TEST_DB_NAME="micgenerp"
TEST_DB_PASSWORD="postgres"

TEST_REDIS_HOST="192.168.2.180"
TEST_REDIS_PORT="6379"
TEST_REDIS_PASSWORD="zhongzao"

LOCAL_DB_HOST="localhost"
LOCAL_DB_PORT="5432"
LOCAL_DB_USER="postgres"
LOCAL_DB_NAME="micgenerp"

LOCAL_REDIS_HOST="localhost"
LOCAL_REDIS_PORT="6379"
LOCAL_REDIS_PASSWORD="zhongzao"

BACKUP_DIR="./backups"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

mkdir -p "$BACKUP_DIR"

echo "=========================================="
echo "数据迁移脚本"
echo "=========================================="
echo ""

# 1. 备份 PostgreSQL
echo "步骤 1: 备份 PostgreSQL 数据库..."
export PGPASSWORD="$TEST_DB_PASSWORD"
pg_dump -h "$TEST_DB_HOST" -p "$TEST_DB_PORT" -U "$TEST_DB_USER" \
  -d "$TEST_DB_NAME" -F c -f "$BACKUP_DIR/micgenerp_${TIMESTAMP}.dump"

echo "✓ PostgreSQL 备份完成: $BACKUP_DIR/micgenerp_${TIMESTAMP}.dump"
echo ""

# 2. 恢复 PostgreSQL
echo "步骤 2: 恢复 PostgreSQL 数据库到本地..."
export PGPASSWORD="postgres"
pg_restore -h "$LOCAL_DB_HOST" -p "$LOCAL_DB_PORT" -U "$LOCAL_DB_USER" \
  -d "$LOCAL_DB_NAME" -c "$BACKUP_DIR/micgenerp_${TIMESTAMP}.dump"

echo "✓ PostgreSQL 恢复完成"
echo ""

# 3. 备份 Redis
echo "步骤 3: 备份 Redis 数据..."
redis-cli -h "$TEST_REDIS_HOST" -p "$TEST_REDIS_PORT" -a "$TEST_REDIS_PASSWORD" \
  --rdb "$BACKUP_DIR/redis_${TIMESTAMP}.rdb"

echo "✓ Redis 备份完成: $BACKUP_DIR/redis_${TIMESTAMP}.rdb"
echo ""

# 4. 恢复 Redis
echo "步骤 4: 恢复 Redis 数据到本地..."
# 停止 Redis
docker stop pms-redis 2>/dev/null || true

# 复制 RDB 文件
docker cp "$BACKUP_DIR/redis_${TIMESTAMP}.rdb" pms-redis:/data/dump.rdb

# 启动 Redis
docker start pms-redis

echo "✓ Redis 恢复完成"
echo ""

echo "=========================================="
echo "数据迁移完成！"
echo "=========================================="
echo "备份文件保存在: $BACKUP_DIR"
echo ""
```

### Windows PowerShell 版本

创建 `scripts/deploy/migrate_data.ps1`:

```powershell
# 数据库和 Redis 数据迁移脚本 (PowerShell)

$ErrorActionPreference = "Stop"

# 配置
$TestDbHost = "192.168.2.172"
$TestDbPort = "5432"
$TestDbUser = "postgres"
$TestDbName = "micgenerp"
$TestDbPassword = "postgres"

$TestRedisHost = "192.168.2.180"
$TestRedisPort = "6379"
$TestRedisPassword = "zhongzao"

$LocalDbHost = "localhost"
$LocalDbPort = "5432"
$LocalDbUser = "postgres"
$LocalDbName = "micgenerp"

$BackupDir = ".\backups"
$Timestamp = Get-Date -Format "yyyyMMdd_HHmmss"

New-Item -ItemType Directory -Force -Path $BackupDir | Out-Null

Write-Host "==========================================" -ForegroundColor Cyan
Write-Host "数据迁移脚本" -ForegroundColor Cyan
Write-Host "==========================================" -ForegroundColor Cyan
Write-Host ""

# 1. 备份 PostgreSQL
Write-Host "步骤 1: 备份 PostgreSQL 数据库..." -ForegroundColor Yellow
$env:PGPASSWORD = $TestDbPassword
$backupFile = Join-Path $BackupDir "micgenerp_$Timestamp.dump"

# 需要安装 PostgreSQL 客户端工具
pg_dump -h $TestDbHost -p $TestDbPort -U $TestDbUser `
  -d $TestDbName -F c -f $backupFile

Write-Host "✓ PostgreSQL 备份完成: $backupFile" -ForegroundColor Green
Write-Host ""

# 2. 恢复 PostgreSQL
Write-Host "步骤 2: 恢复 PostgreSQL 数据库到本地..." -ForegroundColor Yellow
$env:PGPASSWORD = "postgres"
pg_restore -h $LocalDbHost -p $LocalDbPort -U $LocalDbUser `
  -d $LocalDbName -c $backupFile

Write-Host "✓ PostgreSQL 恢复完成" -ForegroundColor Green
Write-Host ""

# 3. 备份 Redis
Write-Host "步骤 3: 备份 Redis 数据..." -ForegroundColor Yellow
$redisBackupFile = Join-Path $BackupDir "redis_$Timestamp.rdb"

# 需要安装 Redis 客户端
redis-cli -h $TestRedisHost -p $TestRedisPort -a $TestRedisPassword `
  --rdb $redisBackupFile

Write-Host "✓ Redis 备份完成: $redisBackupFile" -ForegroundColor Green
Write-Host ""

# 4. 恢复 Redis
Write-Host "步骤 4: 恢复 Redis 数据到本地..." -ForegroundColor Yellow
docker stop pms-redis 2>$null
docker cp $redisBackupFile pms-redis:/data/dump.rdb
docker start pms-redis

Write-Host "✓ Redis 恢复完成" -ForegroundColor Green
Write-Host ""

Write-Host "==========================================" -ForegroundColor Green
Write-Host "数据迁移完成！" -ForegroundColor Green
Write-Host "==========================================" -ForegroundColor Green
Write-Host "备份文件保存在: $BackupDir" -ForegroundColor Yellow
Write-Host ""
```


## ⚠️ 注意事项

### 1. 数据一致性

- **建议在业务低峰期执行迁移**
- 迁移期间测试环境可能无法使用
- 考虑使用 `--single-transaction` 选项（PostgreSQL）保证一致性

### 2. 版本兼容性

- **PostgreSQL**: 确保本地版本 >= 测试环境版本
- **Redis**: RDB 文件通常向后兼容，但建议版本一致

### 3. 数据大小

- 大数据库可能需要较长时间
- 建议先检查数据库大小：
  ```sql
  SELECT pg_size_pretty(pg_database_size('micgenerp'));
  ```

### 4. 权限问题

- 确保有数据库备份权限
- 确保有文件系统写入权限
- Docker 容器需要正确的文件权限

### 5. 网络连接

- 确保能访问测试环境的数据库和 Redis
- 检查防火墙规则
- 考虑使用 VPN 或跳板机

## ✅ 验证迁移结果

### PostgreSQL 验证

```bash
# 检查表数量
docker exec -it pms-postgres psql -U postgres -d micgenerp -c "
  SELECT COUNT(*) FROM information_schema.tables 
  WHERE table_schema = 'public';
"

# 检查数据量
docker exec -it pms-postgres psql -U postgres -d micgenerp -c "
  SELECT schemaname, tablename, 
         pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
  FROM pg_tables 
  WHERE schemaname = 'public'
  ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC
  LIMIT 10;
"
```

### Redis 验证

```bash
# 检查 key 数量
docker exec -it pms-redis redis-cli -a zhongzao DBSIZE

# 检查特定 key
docker exec -it pms-redis redis-cli -a zhongzao KEYS "*"

# 检查内存使用
docker exec -it pms-redis redis-cli -a zhongzao INFO memory
```

## 🚨 故障排除

### PostgreSQL 恢复失败

```bash
# 查看详细错误
pg_restore -h localhost -p 5432 -U postgres -d micgenerp \
  -v -c backup.dump 2>&1 | tee restore.log

# 常见问题：
# 1. 权限不足：检查用户权限
# 2. 对象已存在：使用 -c 参数清理
# 3. 编码问题：设置正确的客户端编码
```

### Redis 恢复失败

```bash
# 检查 RDB 文件是否有效
file dump.rdb

# 检查 Redis 日志
docker logs pms-redis

# 手动加载 RDB
docker exec -it pms-redis redis-cli -a zhongzao
> CONFIG SET dir /data
> CONFIG SET dbfilename dump.rdb
> BGSAVE
```
