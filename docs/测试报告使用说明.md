# 测试报告使用说明

## 📊 现代化HTML测试报告

AI_TEST框架提供了现代化的HTML测试报告，使用Bootstrap 5和Chart.js创建，样式美观、专业。

---

## ✨ 报告特性

### 🎨 美观设计
- ✅ **渐变背景** - 优雅的紫色渐变背景
- ✅ **卡片式布局** - 现代化的卡片设计
- ✅ **响应式设计** - 完美适配各种屏幕尺寸
- ✅ **图标支持** - Bootstrap Icons图标
- ✅ **动画效果** - 悬停和过渡动画

### 📈 数据可视化
- ✅ **饼图** - 测试结果分布（通过/失败）
- ✅ **柱状图** - 各步骤执行时间统计
- ✅ **统计卡片** - 通过、失败、总计、通过率
- ✅ **状态徽章** - 清晰的测试状态标识

### 📋 详细信息
- ✅ **测试步骤详情** - 每个步骤的执行结果
- ✅ **错误信息** - 失败步骤的错误详情
- ✅ **响应信息** - 可折叠的响应详情
- ✅ **协议标识** - 显示使用的协议类型
- ✅ **执行时间** - 每个步骤的执行时间

---

## 🚀 使用方法

### 基本使用

运行测试时会自动生成HTML报告：

```bash
python main.py cases/api/examples/user_query.yaml
```

报告会保存在 `reports/` 目录下，文件名格式为：
```
{用例名}_report_{时间戳}.html
```

例如：
```
user_query_report_20251031_101517.html
```

### 不生成报告

如果不需要生成报告，可以使用 `--no-report` 参数：

```bash
python main.py cases/api/examples/user_query.yaml --no-report
```

## 📄 报告内容

### 1. 报告头部
- 测试用例名称
- 渐变背景设计

### 2. 统计卡片
- **通过**: 通过的测试步骤数（绿色）
- **失败**: 失败的测试步骤数（红色）
- **总计**: 总测试步骤数（蓝色）
- **通过率**: 测试通过率（紫色）

### 3. 状态徽章
- **PASS**: 所有测试通过（绿色徽章）
- **FAIL**: 存在失败测试（红色徽章）

### 4. 图表区域
- **饼图**: 测试结果分布
  - 通过（绿色）
  - 失败（红色）
  
- **柱状图**: 各步骤执行时间
  - X轴：步骤名称
  - Y轴：执行时间（秒）

### 5. 测试信息
- 用例名称
- 用例编码（如果有）
- 用例路径
- 执行时间
- 总耗时

### 6. 测试步骤详情
每个步骤显示：
- ✅ **步骤名称** - 测试步骤描述
- ✅ **状态图标** - 通过/失败图标
- ✅ **状态徽章** - PASS/FAIL标识
- ✅ **协议标识** - HTTP/WebService/WebSocket等
- ✅ **执行时间** - 步骤耗时
- ✅ **错误信息** - 失败时的错误详情（可展开）
- ✅ **响应详情** - 可折叠的响应信息

## 🔍 查看报告

### 方式1: 直接打开
在文件管理器中找到报告文件，双击打开即可在浏览器中查看。

### 方式2: 浏览器打开
```bash
# Windows
start reports/user_query_report_20251031_101517.html

# macOS
open reports/user_query_report_20251031_101517.html

# Linux
xdg-open reports/user_query_report_20251031_101517.html
```

### 方式3: HTTP服务器
```bash
# Python 3
cd reports
python -m http.server 8000

# 然后浏览器访问
# http://localhost:8000/user_query_report_20251031_101517.html
```

## 📊 报告数据结构

报告基于测试执行结果生成，包含以下信息：

```python
{
    'case_name': '测试用例名称',
    'case_code': '测试用例编码',
    'case_path': '测试用例文件路径',
    'total_steps': 5,           # 总步骤数
    'passed_steps': 4,          # 通过步骤数
    'failed_steps': 1,          # 失败步骤数
    'pass_rate': 80.0,          # 通过率
    'execution_time': 2.5,      # 总执行时间（秒）
    'status': 'PASS' or 'FAIL',  # 测试状态
    'timestamp': '2025-10-31 10:15:17',  # 执行时间
    'step_results': [            # 步骤结果列表
        {
            'step_name': '步骤名称',
            'passed': True,      # 是否通过
            'errors': [],        # 错误列表
            'duration': 0.5,     # 执行时间（秒）
            'response': {...}    # 响应信息
        },
        ...
    ]
}
```

## 🎨 自定义样式

报告使用了以下技术：

- **Bootstrap 5.3.2** - UI框架
- **Bootstrap Icons 1.11.1** - 图标库
- **Chart.js 4.4.0** - 图表库

所有样式都是内联的，报告文件是完全自包含的，可以独立查看，无需外部依赖。

## 🔧 高级功能

- 状态码
- 协议类型
- 请求URL
- 请求方法
- 其他响应元数据

### 错误信息查看

失败的步骤会显示：
- 黄色警告框
- 错误详情列表
- 每个错误独立显示

---

## 📝 注意事项

1. **网络连接**: 报告使用CDN加载CSS和JS，需要网络连接才能正常显示样式
2. **浏览器兼容**: 建议使用现代浏览器（Chrome、Firefox、Edge、Safari）
3. **文件路径**: 报告文件保存在 `reports/` 目录下
4. **文件命名**: 报告文件名包含时间戳，不会覆盖之前生成的报告
