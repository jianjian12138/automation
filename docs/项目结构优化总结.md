## 📝 使用方法

### 验证安装

```bash
cd AI_TEST
python tools/verify_installation.py
```

### 运行演示

```bash
python tools/demos/demo_smart_data.py
```

### 使用修复工具

```bash
# 单个用例修复
python tools/fix/auto_fix_test_cases.py cases/api/examples/add.yaml

# 失败诊断
python tools/fix/failure_diagnostic_tool.py cases/api/examples/add.yaml

# 批量修复
python tools/fix/smart_batch_fix.py cases/api/
```

### 生成数据库表清单

```bash
# 生成分片9清单
python database_schemas/generate_shard_9_list.py

# 生成基础公共库清单
python database_schemas/list_base_schemas.py

# 生成完整清单
python database_schemas/merge_all_tables.py
```
