# 录制工具使用说明

## 问题：PowerShell 执行策略限制

如果遇到 "禁止运行脚本" 的错误，可以使用以下方法：

### 方法一：使用批处理文件（推荐，最简单）

```cmd
# 使用快速录制脚本
cd F:\BaiduNetdiskDownload\AT\AI_TEST
scripts\快速录制.bat "销售合同" "http://192.168.2.112:3356/?code=190787210592256000"

# 或使用完整版
scripts\record_testcase.bat "销售合同" "http://192.168.2.112:3356/?code=190787210592256000"
```

### 方法二：临时绕过 PowerShell 执行策略

```powershell
# 在当前会话中临时允许执行脚本
powershell -ExecutionPolicy Bypass -File .\scripts\record_testcase.ps1 "销售合同" "http://192.168.2.112:3356/?code=190787210592256000"
```

### 方法三：直接使用命令（最直接）

```cmd
# 1. 启动录制
cd F:\BaiduNetdiskDownload\AT\AI_TEST
python -m playwright codegen --viewport-size=1920,1080 "http://192.168.2.112:3356/?code=190787210592256000"

# 2. 在浏览器中执行操作后，保存代码到 files\temporary\codegen_xxx.py

# 3. 转换为 YAML
python tools\playwright_codegen_to_yaml.py --input files\temporary\codegen_xxx.py --output cases\web\6000\销售合同.yaml --case-name "销售合同"
```

## 推荐使用方式

### 快速录制（最简单）

```cmd
cd F:\BaiduNetdiskDownload\AT\AI_TEST
scripts\快速录制.bat "销售合同" "http://192.168.2.112:3356/?code=190787210592256000"
```

这个批处理文件会：
1. 自动创建必要的目录
2. 启动 codegen 录制
3. 提示你保存代码
4. 自动转换为 YAML

## 录制步骤

1. **运行录制脚本**
   ```cmd
   scripts\快速录制.bat "用例名称" "URL"
   ```

2. **在浏览器中操作**
   - 最大化浏览器窗口（重要！）
   - 执行你要测试的操作流程
   - 在 Playwright Inspector 中点击 'Copy'

3. **保存代码**
   - 将复制的代码保存到提示的文件路径
   - 通常是 `files\temporary\codegen_YYYYMMDD_HHMMSS.py`

4. **自动转换**
   - 脚本会自动检测文件并转换为 YAML
   - 或手动运行转换命令

## 转换命令

如果录制后需要手动转换：

```cmd
python tools\playwright_codegen_to_yaml.py --input files\temporary\codegen_xxx.py --output cases\web\6000\用例名称.yaml --case-name "用例名称"
```

## 执行用例

转换完成后，执行用例：

```cmd
python main.py cases\web\6000\用例名称.yaml --type web
```

## 工具文件说明

- `scripts\快速录制.bat` - 快速录制脚本（推荐）
- `scripts\record_testcase.bat` - 完整功能录制脚本
- `scripts\record_testcase.ps1` - PowerShell 版本（需要执行策略）
- `scripts\快速转换录制文件.ps1` - 快速转换工具

## 常见问题

### Q: 批处理文件无法运行？

A: 确保在项目根目录运行，或使用完整路径。

### Q: 录制后找不到文件？

A: 检查 `files\temporary` 目录，确保代码已保存到正确路径。

### Q: 转换失败？

A: 检查录制的 Python 代码格式是否正确，确保是 Playwright codegen 生成的代码。
