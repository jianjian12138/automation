# 一键安装和启动指南

## 🚀 快速开始（3步完成）

### 步骤1: 运行一键安装脚本

#### Windows

```powershell
# 以管理员身份运行PowerShell
powershell -ExecutionPolicy Bypass -File scripts\setup\install_and_start.ps1
```

#### Linux/Mac

```bash
# 运行安装脚本
bash scripts/setup/install_and_start.sh
```

### 步骤2: 按照提示操作

脚本会自动：
1. ✅ 检查Docker安装状态
2. ✅ 如果未安装，提供安装选项（自动或手动）
3. ✅ 启动Jenkins容器
4. ✅ 等待Jenkins就绪
5. ✅ 获取初始密码

### 步骤3: 访问Jenkins

1. **打开浏览器**: http://localhost:8080
2. **输入初始密码**（脚本会显示）
3. **安装推荐的插件**
4. **创建管理员用户**
5. **配置Pipeline项目**

---

## 📋 脚本功能

### 自动完成的任务

| 任务 | 说明 |
|------|------|
| **Docker检查** | 自动检测Docker是否已安装 |
| **Docker安装** | 提供自动安装或手动安装指导 |
| **Docker验证** | 验证Docker服务是否正常运行 |
| **Jenkins启动** | 使用docker-compose启动Jenkins |
| **Jenkins验证** | 等待并验证Jenkins服务可用性 |
| **密码获取** | 自动获取Jenkins初始管理员密码 |
| **信息显示** | 显示访问信息和后续操作步骤 |

## ⚙️ 高级选项

### Windows

```powershell
# 跳过Docker检查（假设已安装）
powershell -ExecutionPolicy Bypass -File scripts\setup\install_and_start.ps1 -SkipDockerCheck

# 跳过Jenkins启动（仅安装Docker）
powershell -ExecutionPolicy Bypass -File scripts\setup\install_and_start.ps1 -SkipJenkinsStart
```

### Linux/Mac

```bash
# 跳过Docker检查（假设已安装）
bash scripts/setup/install_and_start.sh --skip-docker-check

# 跳过Jenkins启动（仅安装Docker）
bash scripts/setup/install_and_start.sh --skip-jenkins-start
```

## 🔧 常见问题

### Q1: 需要管理员权限

**错误**: "需要管理员权限！"

**解决**: 
- Windows: 以管理员身份运行PowerShell
- Linux/Mac: 使用sudo运行脚本（仅部分操作需要）

### Q2: Docker安装失败

**错误**: "Docker安装失败"

**解决**:
1. 检查系统要求（Windows 10/macOS 10.15/Linux）
2. 确保有足够的磁盘空间
3. 查看详细错误信息
4. 尝试手动安装（方式2）

### Q3: Jenkins启动超时

**错误**: "Jenkins启动超时"

**解决**:
1. 检查Docker是否正常运行: `docker ps`
2. 查看Jenkins日志: `docker logs ai_test_jenkins`
3. 手动访问 http://localhost:8080 检查状态
4. 可能需要更长时间（首次启动需要下载镜像）

### Q4: 端口已被占用

**错误**: "端口8080已被占用"

**解决**:
1. 修改 `docker-compose.yml` 中的端口映射
2. 或停止占用端口的程序
