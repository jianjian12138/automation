## 🎓 最佳实践

### 1. 选择器策略

```yaml
# ✅ 推荐：按优先级使用
# 1. data-testid（最稳定）
button_登录: t,login-button

# 2. role（Playwright 推荐）
button_登录: r,button,登录

# 3. id
button_登录: s,#login-button

# ❌ 避免：仅使用文本（不稳定）
button_登录: x,//button[contains(text(),"登录")]
```

### 2. 等待策略

```yaml
# ✅ 推荐：智能等待
- action: $navigate(&url)
- action: $wait_for_network_idle()

# ❌ 避免：固定 sleep
- action: $navigate(&url)
  sleep: 2
```

### 3. 标签使用

```yaml
# ✅ 推荐：按风险级别组织
tags:
  - smoke      # 冒烟测试（每次提交运行）
  - critical   # 关键功能（发版前运行）
  - full       # 完整回归（夜间运行）
```

### 4. 智能定位

```yaml
# ✅ 推荐：固定选择器优先，AI 备选
- action: $smart_click(&button_登录, description="登录按钮")

# ❌ 避免：所有元素都使用 AI（成本高）
- action: $ai_locate_element("登录按钮")
```
