## 功能名称
用户登录

## 功能描述
用户通过用户名和密码登录系统，登录成功后获取访问token。token用于后续API调用的身份验证，有效期为24小时。

## 接口定义

### 基本信息
- **接口路径**: `/api/login`
- **请求方法**: `POST`
- **Content-Type**: `application/json`
- **是否需要认证**: 否

### 请求参数

| 参数名 | 类型 | 必填 | 约束 | 说明 | 示例 |
|--------|------|------|------|------|------|
| username | string | 是 | 长度3-20，只能包含字母、数字、下划线 | 用户名 | "testuser" |
| password | string | 是 | 长度6-20，必须包含字母和数字 | 密码 | "password123" |
| remember | boolean | 否 | true/false | 是否记住登录（延长token有效期至7天） | false |

### 请求示例

```json
{
  "username": "testuser",
  "password": "password123",
  "remember": false
}
```

### 响应格式

#### 成功响应 (200)
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMywidXNlcm5hbWUiOiJ0ZXN0dXNlciJ9.xxx",
    "userId": 123,
    "username": "testuser",
    "expiresIn": 86400,
    "userInfo": {
      "email": "test@example.com",
      "nickname": "测试用户",
      "avatar": "https://example.com/avatar.jpg"
    }
  }
}
```

#### 失败响应 (400)
```json
{
  "code": 400,
  "message": "错误描述",
  "data": null
}
```

#### 失败响应 (403)
```json
{
  "code": 403,
  "message": "账户已锁定，请30分钟后重试",
  "data": {
    "lockTime": "2025-10-30 16:30:00",
    "remainingSeconds": 1800
  }
}
```

## 业务规则

### 1. 认证规则
- 用户名和密码必须完全匹配（密码区分大小写）
- 用户名不区分大小写
- 密码加密存储，使用bcrypt算法

### 2. 安全规则
- 同一IP连续密码错误3次后锁定该IP 30分钟
- 同一用户名连续密码错误5次后锁定账户30分钟
- token有效期：
  - 默认24小时
  - remember=true时为7天
- 同一账户同时只能有一个有效token（新登录会使旧token失效）

### 3. 参数校验规则
- 用户名：
  - 必填
  - 长度3-20
  - 只能包含字母、数字、下划线
  - 不能以数字开头
  - 不能包含空格
  
- 密码：
  - 必填
  - 长度6-20
  - 必须包含至少一个字母和一个数字
  - 可以包含特殊字符（!@#$%^&*）
  - 不能包含空格

### 4. Token使用规则
- 后续请求需在Header中携带：`Authorization: Bearer {token}`
- token过期后需要重新登录
- token被篡改会返回401错误

## 异常处理

### 参数校验异常 (400)

| 场景 | 返回消息 | 说明 |
|------|---------|------|
| 缺少username | "用户名不能为空" | 请求体中没有username字段 |
| 缺少password | "密码不能为空" | 请求体中没有password字段 |
| username长度<3 | "用户名长度必须在3-20之间" | 用户名过短 |
| username长度>20 | "用户名长度必须在3-20之间" | 用户名过长 |
| username格式错误 | "用户名只能包含字母、数字、下划线" | 包含非法字符 |
| username以数字开头 | "用户名不能以数字开头" | 格式验证失败 |
| password长度<6 | "密码长度必须在6-20之间" | 密码过短 |
| password长度>20 | "密码长度必须在6-20之间" | 密码过长 |
| password格式错误 | "密码必须包含字母和数字" | 不符合复杂度要求 |
| remember类型错误 | "remember参数必须为布尔值" | 类型校验失败 |

### 业务逻辑异常

| 场景 | HTTP状态码 | 返回消息 | 说明 |
|------|-----------|---------|------|
| 用户名不存在 | 400 | "用户名或密码错误" | 用户未注册（安全考虑，不明确提示用户名不存在） |
| 密码错误 | 400 | "用户名或密码错误，还可尝试N次" | 密码不匹配，N为剩余尝试次数 |
| 账户被锁定 | 403 | "账户已锁定，请30分钟后重试" | 密码错误超过5次 |
| IP被锁定 | 403 | "IP已被锁定，请30分钟后重试" | 同一IP密码错误超过3次 |
| 账户被禁用 | 403 | "账户已被禁用，请联系管理员" | 管理员手动禁用账户 |

### 系统异常 (500)

| 场景 | 返回消息 | 说明 |
|------|---------|------|
| 数据库连接失败 | "系统繁忙，请稍后重试" | 内部错误 |
| Token生成失败 | "登录失败，请重试" | 内部错误 |

## 依赖接口

- 无（独立接口）

## 数据库操作

### 查询
- 查询用户表（users）：根据username查询用户信息
- 查询登录记录表（login_logs）：记录登录历史

### 更新
- 更新用户表：更新last_login_time
- 更新登录失败记录表：记录失败次数和锁定状态

## 性能要求

- 响应时间：< 500ms（P95）
- 并发支持：1000 QPS
- 可用性：99.9%

## 安全要求

- 生产环境必须使用HTTPS
- 密码传输前需前端加密（可选）
- 记录所有登录尝试日志
- 敏感信息（密码）不记录在日志中

## 注意事项

1. **Token存储**
   - 前端需要安全存储token（localStorage或sessionStorage）
   - 避免token泄露

2. **错误提示**
   - 用户名不存在时，不明确提示，避免被扫号
   - 统一返回"用户名或密码错误"

3. **测试环境**
   - 测试账户：testuser / password123
   - 测试环境关闭IP锁定和账户锁定（便于测试）

4. **监控告警**
   - 登录失败率超过10%时告警
   - 单IP登录失败次数过多时告警（可能是攻击）
