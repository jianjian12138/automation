# 录制测试用例指南

## 概述

本指南介绍如何使用 Playwright Codegen 录制测试用例，并转换为框架的 YAML 格式。

## 快速开始

### 方法一：使用自动化脚本（推荐）

```powershell
# 1. 启动录制
.\scripts\录制测试用例.ps1 "用例名称" "URL" "输出目录"

# 示例：录制登录用例
.\scripts\录制测试用例.ps1 "登录测试" "http://192.168.2.112:3356/?code=190787210592256000" "cases/web/6000"

# 示例：录制创建订单用例
.\scripts\录制测试用例.ps1 "创建订单" "http://192.168.2.112:3356" "cases/web/6000"
```

脚本会自动：
1. 检查 Playwright 安装
2. 启动 codegen 录制
3. 提示保存录制文件
4. 可选自动转换为 YAML

### 方法二：手动录制和转换

#### 步骤 1: 启动录制

```powershell
# 使用录制脚本（推荐）
.\scripts\录制测试用例.ps1

# 或直接使用 codegen
python -m playwright codegen --viewport-size=1920,1080 http://192.168.2.112:3356/?code=190787210592256000
```

#### 步骤 2: 执行操作

在打开的浏览器中：
1. **最大化浏览器窗口**（重要！）
2. 执行你要测试的操作流程
3. 在 Playwright Inspector 中点击 'Copy' 按钮
4. 将代码保存到 `files/temporary/codegen_xxx.py`

#### 步骤 3: 转换为 YAML

```powershell
# 使用快速转换脚本
.\scripts\快速转换录制文件.ps1 "files\temporary\codegen_xxx.py" "用例名称" "cases/web/6000"

# 或直接使用转换工具
python tools\playwright_codegen_to_yaml.py `
  --input files\temporary\codegen_xxx.py `
  --output cases\web\6000\TestCase.yaml `
  --case-name "用例名称"
```

## 录制最佳实践

### 1. 窗口最大化

录制前务必最大化浏览器窗口，确保元素正确显示和定位。

### 2. iframe 处理

- Playwright 会自动识别 iframe，无需手动切换
- 如果页面有多个 iframe，确保点击的是目标 iframe 内的元素
- 转换工具会自动提取 iframe 选择器

### 3. 等待页面加载

- 在关键操作前等待页面加载完成
- 转换工具会自动添加必要的等待时间

### 4. 操作顺序

按照实际业务流程顺序操作：
1. 导航到页面
2. 等待元素出现
3. 输入数据
4. 点击按钮
5. 验证结果

## 转换工具参数

```bash
python tools/playwright_codegen_to_yaml.py \
  --input <录制文件> \          # 必填：Playwright codegen 生成的 Python 文件
  --output <输出文件> \         # 必填：输出的 YAML 用例文件路径
  --case-name <用例名称>        # 可选：用例名称（中文），不提供则自动推断
```

## 转换后的用例结构

转换工具会自动生成：

```yaml
case_name: 用例名称
case_code: TestCaseCode
priority: 1
case_variables:
  url: http://...
  iframe_selector: x,//iframe[...]
  # 其他选择器变量...
steps:
  - step_name: Step 01 - 导航到页面
    actions:
      - action: $navigate(&url)
        sleep: 2
  # 其他步骤...
```

## 常见问题

### Q: 录制时浏览器窗口没有最大化？

A: `--viewport-size` 只设置视口大小，不是窗口大小。请手动点击浏览器窗口的最大化按钮。

### Q: 如何找到正确的 iframe 选择器？

A: 
1. 打开浏览器开发者工具
2. 查看 Elements 面板
3. 找到 iframe 元素
4. 右键 -> Copy -> Copy selector 或 Copy XPath
5. 在转换后的 YAML 中修改 `iframe_selector`

### Q: 转换后的选择器不正确？

A: 可以手动修改 `case_variables` 中的选择器。确保选择器能够唯一标识元素。

### Q: 如何验证转换后的用例？

A: 
```powershell
python main.py cases/web/6000/TestCase.yaml --type web
```

## 工具脚本说明

### `scripts/录制测试用例.ps1`

通用录制脚本，支持：
- 自动检查 Playwright 安装
- 启动 codegen 录制
- 可选自动转换

**参数：**
- `CaseName`: 用例名称（可选）
- `Url`: 录制目标 URL（默认：登录页面）
- `OutputDir`: 输出目录（默认：cases/web/6000）

### `scripts/快速转换录制文件.ps1`

快速转换脚本，用于将已录制的 Python 文件转换为 YAML。

**参数：**
- `InputFile`: 录制文件路径（必填）
- `CaseName`: 用例名称（可选）
- `OutputDir`: 输出目录（默认：cases/web/6000）
