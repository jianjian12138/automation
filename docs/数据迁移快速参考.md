# 数据迁移快速参考

## ⚡ 最快方式（一键迁移）

```bash
# 方式1: 使用 Python 脚本（推荐，不依赖命令行工具）
pip install psycopg2-binary redis
python scripts/deploy/migrate_data.py

# 方式2: 使用 Shell 脚本（需要安装 PostgreSQL 和 Redis 客户端）
bash scripts/deploy/migrate_data.sh

# 方式3: 使用 PowerShell（Windows）
powershell -ExecutionPolicy Bypass -File scripts/deploy/migrate_data.ps1
```

---

## 📋 手动迁移步骤

### PostgreSQL 数据库

```bash
# 步骤1: 备份（在能访问测试数据库的机器上）
export PGPASSWORD=postgres
pg_dump -h 192.168.2.172 -p 5432 -U postgres -d micgenerp \
  -F c -f micgenerp_backup.dump

# 步骤2: 传输文件到本地（使用 SCP、FTP 等）

# 步骤3: 恢复（本地）
docker exec -i pms-postgres pg_restore -U postgres -d micgenerp -c < micgenerp_backup.dump
```

### Redis 缓存

```bash
# 步骤1: 备份（在能访问测试 Redis 的机器上）
redis-cli -h 192.168.2.180 -p 6379 -a zhongzao --rdb dump.rdb

# 步骤2: 传输文件到本地

# 步骤3: 恢复（本地）
docker stop pms-redis
docker cp dump.rdb pms-redis:/data/dump.rdb
docker start pms-redis
```

## 🔍 验证迁移结果

```bash
# PostgreSQL - 检查表数量
docker exec -it pms-postgres psql -U postgres -d micgenerp \
  -c "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema = 'public';"

# Redis - 检查 Key 数量
docker exec -it pms-redis redis-cli -a zhongzao DBSIZE
```

## ⚠️ 注意事项

1. **数据一致性**: 建议在业务低峰期执行
2. **版本兼容**: 确保本地 PostgreSQL 版本 >= 测试环境版本
3. **网络连接**: 确保能访问测试环境的数据库和 Redis
4. **权限问题**: 确保有备份和恢复权限
5. **数据大小**: 大数据库可能需要较长时间
